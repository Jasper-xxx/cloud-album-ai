## 二、当前入口与安全

| 入口 | 当前行为 |
| --- | --- |
| 浏览器 → 后端 | 有效 Sa-Token，绑定登录账号 |
| Dify → 后端 | `X-Agent-Service-Key`，绑定配置的 `AGENT_OWNER_USER_ID` |
| 后端 → AI | `X-AI-Service-Key`，两端使用相同 `AI_SERVICE_KEY` |
| 公开能力清单 | `GET /agent/capabilities` 可以匿名读取能力，不读取照片 |
| 前端助手 | 完整 `/chat/` WebApp，历史会话菜单、单图附件、“操作记录与照片”页；关闭浮窗保留 iframe |

旧的 `AGENT_AUTH_ENABLED=false` 与 `AGENT_DEV_USER_ID` 免登录回退已移除。Dify 凭据不会按 WebApp 访问者切换用户；绑定 A 的应用只能操作 A 的图库，不能把其密钥放进浏览器。

根目录 `.env` 为共享配置入口，启动脚本不再从 `tmp/agent-local-runtime.json` 注入密钥。AI 可选的 `ai-service/.env` 与进程环境变量可能覆盖根配置，需保持鉴权值一致。前端 Vite 也从根目录读取 `VITE_*`，只允许公开地址等浏览器配置；两把服务密钥不能加 `VITE_` 前缀。

## 三、功能总览

### 3.1 只读查询与后台发现

| 功能 | 工具 | 当前实现与边界 |
| --- | --- | --- |
| 能力边界 | `getAgentCapabilities` | 公布可用工具类型，模式标识保留 `trusted_agent_full_p0_p4`，不表示全部在线验收通过 |
| 普通照片搜索 | `searchFiles` | 分页最多 50，支持媒体类型、时间排序、普通相册、标签、地点、设备查询 |
| 组合搜索 | `advancedSearchFiles` | 日期、多标签 AND/OR、地点、设备、普通/人物相册 ID 或精确名称、媒体与数据完整性；返回条件摘要和空结果放宽建议 |
| 图库分析 | `analyzeLibrary` | 缺标签/地点/特征/AI 分析、相似候选与异常任务等只读建议，不自动整理 |
| 相册、标签和人物 | `listAlbums / listLocationAlbums / listModelAlbums / listTags / listPeople` | 当前认证账号范围；人物姓名或关系只来自用户输入 |
| 相似照片发现 | `discoverSimilarFiles` | 持久化后台任务，先返回 `jobId/status/progress`；操作记录查看结果或取消。候选不是自动删除依据 |
| 附件查询 | `searchByAttachment` | 单张附件作为查询图，不写入图库；后端支持模式、相册、标签和尺寸筛选 |

普通相册与人物相册条件分别绑定当前用户并取交集，不能把人物名代替标签。Dify 只读规划可使用最近 8 轮查询上下文处理“继续/下一页”，有歧义先澄清；不恢复历史写参数。

相似发现保留现有队列、上限、超时、取消和缓存实现，不继续扩展算法或重复性能测试。返回“已受理”不表示完成。它与附件以图搜图是不同链路。

### 3.2 需真实预览和确认的整理

| 操作族 | 当前能力 | 主要边界 |
| --- | --- | --- |
| 相册 | 创建、创建并加入、加入已有相册、移出相册 | 最多 100 张；移出相册不删除照片；纯创建允许空照片集合 |
| 标签 | 添加/移除标签 | 最多 100 张；共享物理文件仍有其他活跃用户时跳过，不影响对照账号 |
| AI 标签任务 | 预览并提交 `autoAdd=false` 持久化任务、查询状态与候选 | 最多 50 张；每图最多 5 条达到阈值的建议；完成不代表写入 |
| 应用候选标签 | 校验任务来源、选择全部/标签名/文件—标签对，再预览执行 | 最多 100 条；生成建议与写入建议分别确认 |
| P3 维护 | 特征提取、地点修正、回收站恢复、人物重命名/显隐/移动/合并 | 冻结目标、再校验所有权；恢复和特征提取最多 50 张 |
| P4 资源与回收 | 文件/相册分享或下载授权、移入回收站、删除相册 | 90 秒确认；资源授权持久化且令牌仅存哈希 |
| P4 不可逆操作 | 已有永久删除/清空回收站代码 | 单次最多 10 个；真实操作与完整验收延期，不作为本轮验证任务 |

相册/标签“最近 N 张”使用 `searchType=latest` 与 `selectionLimit=1～100`；AI 标签任务上限 50。服务端冻结真实照片，不用准备添加的新标签反向检索。创建空相册按 `success` 与新建相册数报告，照片变化数为 0 不代表失败。

文件分享/下载/移入回收站最多 20 个目标，删除相册最多 5 个，相册分享/下载/连同照片删除最多冻结 100 个文件。分享有效期 1～30 天；分享/下载执行前复核内容快照，删除相册只处理预览冻结且执行时仍在目标相册内的照片。

### 3.3 回收站恢复与自然语言删除

“把相册 测试旅行 里面的图片删掉”进入 `move_files_to_recycle_bin`，先按当前主人唯一相册名解析真实照片并预览，不擅自永久删除。多相册、模糊名称和带子集筛选条件先澄清或搜索。

“把回收站的照片恢复”使用 `restore_files` 和显式 `allRecycleImages=true`，只恢复当前主人回收站中的图片，最多 50 张；超限要求缩小范围，空结果不签发确认。空 `fileIds` 不能隐式代表全量恢复。

软删除保留相册成员、封面、标签和相似分组关系，正常查询过滤回收站内容；恢复后恢复可见性。到期清理按用户关系及原删除时间处理，物理对象进入事务提交后的 GC 队列，不把单个用户移入回收站当作立即删除共享对象。

### 3.4 附件保存与前端

当前 DSL 已包含两个附件工具节点，`sys.files` 的第一份 File 变量绑定 multipart `attachment`；界面单次允许一张 JPG/JPEG/PNG/GIF/WEBP。

- “查找和这张图相似度最高的图片”“以图搜图”等自然语言进入查询，不保存附件。
- “保存这张图片”“保存附件”是明确上传授权，直接调用 `uploadAttachment`；这是普通预览确认机制的例外，不需要再发送一次“确认”。
- 同时保存和查询、否定或意图不明先澄清；附件名、临时 URL、视觉描述不能充当 `fileId`。
- 只有后端返回成功和真实标识，才记录 `attachment_file_id`；后续整理仍须真实预览。
- 返回状态未知时不能宣称成功。查询可重试，保存先检查图库避免重复提交。

助手设置优先使用浏览器保存的 WebApp 地址，否则读取根目录 `.env` 的 `VITE_DIFY_AGENT_URL`。旧 `/chatbot/` 自动转为 `/chat/`，左上角可切换历史会话，输入框附件按钮添加图片。前端不另存一套 Dify 聊天记录，也不持有服务端密钥。

## 四、可信确认与会话绑定

预览冻结操作类型、目标、照片及参数，数据库保存载荷哈希、确认 Token/幂等键哈希。记录绑定当前账号、`conversationId` 和工作流版本，执行时复核资源所有权。普通预览默认 300 秒，P4 为 90 秒。

- 新的有效预览只使**同账号同会话**旧预览失效；无变化预览不覆盖有效确认。
- 只接受整条规范化回复精确匹配“确认 / 执行 / 确认执行 / 开始执行 / 可以执行 / 同意执行 / confirm / execute”；“是 / 好的 / 可以 / ok / yes”不执行。
- 执行只接收待执行 ID、Token、幂等键和字面布尔 `confirmed=true`；业务参数不得重新提交。`conversationId` 从 `sys.conversation_id` 通过 query 传递。
- 修改相册、标签、范围或动作必须完整重述新需求并重新预览。
- 原子领取与同凭据幂等结果避免重复副作用；状态不确定先查询，不自动重放写入。
- `PREVIEWED / EXECUTING` 或状态查询失败保留凭据；`SUCCEEDED / FAILED / CANCELLED / EXPIRED` 终态才清除。
- 对话中只展示真实预览、文件名、数量及变化，不把确认凭据送入 LLM。

## 五、接口与数据迁移

当前 Dify 工具入口共 27 个 operation，完整请求/响应以 [OpenAPI](dify-agent-openapi.yaml) 为准。前端还使用：

| 路径 | 用途 |
| --- | --- |
| `GET /agent/activity` | 当前账号操作记录 |
| `GET /agent/discoveryJobs` | 当前账号相似发现任务 |
| `GET /agent/discoveryJobs/{id}` | 任务进度及完成结果 |
| `POST /agent/discoveryJobs/{id}/cancel` | 请求取消当前账号任务 |

这些前端辅助接口不等于已经新增了相应 Dify 工具节点。Agent 预览/执行/状态/取消使用原会话；前端任务结果按账号所有权过滤。

数据库迁移：V6 待执行记录、V7 查询索引、V8 AI 标签批次、V9 会话绑定与锁、V10 资源授权、V11 对象 GC、V12 后台相似发现。V9 之前缺少会话的预览不可继续执行，需新建预览；不要改写或手动重放已应用的迁移。
